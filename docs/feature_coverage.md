# Feature Coverage

Generated by `python scripts/build_feature_coverage.py`. Every row is derived
from the source tree and from the recorded canonical pipeline run, not
maintained by hand.

**Exported** means the feature appeared as a column in
`output/feature_dataset_canonical_validation.csv`. **Granular** means it also
appeared in the question-level or section-level export, which applies to the
Q and S families. **Direct test** means a test names the feature and asserts
on it. Every feature is additionally exercised end to end, because the full
feature dataset is produced and evaluated against ground truth in
`tests/test_end_to_end.py` and in the labelled validation runs.
